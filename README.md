## ◈ About This Repository

Welcome to my **Datheon Python Programming Internship** project repository.

This repository documents my practical learning journey through four Python development projects. Each project focuses on a different programming concept, ranging from fundamental game logic and data processing to filesystem automation and interactive conversational systems.

The objective is simple: transform programming concepts into functional applications while developing problem-solving, debugging, logical thinking, and software development skills.

## 🚀 Project Showcase

### 01 — Hangman Ultimate
**Category:** Game Development | Logic Building

A command-line implementation of the classic Hangman word-guessing game, designed with enhanced gameplay and input handling.

**Key Features**
- Random word selection.
- Hidden-word display with progressive letter revelation.
- Maximum of six incorrect attempts.
- ASCII-based visual game progression.
- Previously guessed letter tracking.
- Duplicate guesses do not consume additional attempts.
- Win and loss conditions.

**Technologies:** Python, Random Module, String Manipulation, Conditional Logic.

**Project Directory:** `task1_hangman/`

---

### 02 — Stock Portfolio Tracker
**Category:** Data Processing | Financial Calculations

A Python-based stock portfolio tracking application that processes stock information and calculates portfolio performance using purchase and current market values.

**Key Features**
- Stock symbol and quantity management.
- Purchase price and current price tracking.
- Portfolio cost-basis calculations.
- Current portfolio valuation.
- Profit and loss calculations.
- Percentage return calculation.
- CSV-based performance logging.
- Input validation.

**Technologies:** Python, CSV, Data Processing, Mathematical Operations.

**Project Directory:** `task2_stock_tracker/`

---

### 03 — Pro File Organizer
**Category:** Automation | Filesystem Management

An automated desktop utility designed to organize cluttered directories by identifying file extensions and moving files into automatically created category folders.

**Key Features**
- Directory scanning using `os.scandir()`.
- Automatic folder creation.
- Extension-based file classification.
- File movement using `shutil.move()`.
- Organized categories:
  - Documents
  - Images
  - Videos
  - Archives
  - Code
- Duplicate filename handling.
- Permission exception handling.
- Operation summary.

**Technologies:** Python, `os`, `shutil`, Filesystem Automation, Exception Handling.

**Project Directory:** `task3_file_organizer/`

---

### 04 — NOVA Terminal Assistant
**Category:** Conversational Systems | Rule-Based Automation

NOVA is an interactive terminal-based assistant that uses keyword matching, regular expressions, and a JSON knowledge base to identify user intents and generate relevant responses.

**Key Features**
- Greeting recognition.
- Basic user-name recognition.
- Multi-intent FAQ matching.
- JSON-powered knowledge base.
- Context-aware follow-up responses.
- Session-based conversation history.
- Help and command handling.
- Graceful exit commands.
- Fallback responses for unrecognized queries.

**Technologies:** Python, Regular Expressions, JSON, pathlib, Object-Oriented Programming.

**Project Directory:** `task4_chatbot/`

**Testing:** All 9 manual test scenarios passed.

## ▶️ Running the Projects

### Prerequisites
- Python 3.x
- Git
- Visual Studio Code or another Python-compatible editor

Clone the repository:

```bash
git clone <your-repository-url>
```

Navigate to the repository:

```bash
cd Datheon_Python_Programming_Internship
```

Enter the required project directory and run its Python file.

Example — NOVA:

```bash
cd task4_chatbot
python chatbot.py
```

For project-specific instructions, refer to the README inside each task folder.
